# 记忆换乘协议
### Memory Transit Protocol — 用最少的 token,到达历史里的任何一场对话

> 不保证直达,保证到达。
> 每一程,只买该程的票。

---

## 两种主流方案,两种浪费

AI 要用你的历史,今天只有两条路,都在浪费:

**路线一:全文注入。** 把相关对话整场塞进上下文。一场长会话是几十万 token——AI 读完 99% 的无关内容,才碰到那 1% 有用的。这是**为不需要的信息付费**。

**路线二:一发检索。** 关键词搜一下,搜到算赢。但你今天说「那个内存问题」,当年的原话是「malloc 池水位」——词对不上就是空手而归。我们用真实数据测过:裸检索首位命中率 **5.2%**,叠加四层增强(字符三元组容错 · 个人词表 · 查询扩展 · 情境加权)提到 **21.7%**——提升 4.2 倍,但本质仍是赌博。这是**为赌错的那次付费**。

一个要你梭哈,一个要你碰运气。

## 换乘协议:第三条路

坐公交的人都懂一个道理:**没有直达车,不代表到不了。** 先看线路图,再上对的线,到站再走两步——每一段都只花该段的钱。

记忆检索同理。关键洞察是:

> **AI 本身就是最强的语义匹配器。它缺的从来不是理解力,是候选词表。**

你说「那个内存问题」,AI 搜不到——但如果先递给它一张**线路图**,上面印着这个项目的高频词:`malloc` `池水位` `footprint`,它瞬间完成「内存问题 → malloc」的映射,然后用**当年的原词**一击命中。

语义映射交给 AI 免费做,检索系统只负责两件事:**递地图,和精确的最后一跳。**

## 五段换乘,token 账单全公开

| 站 | 动作 | 拿到什么 | Token 成本 |
|---|---|---|---|
| **L0 线路图**（规划中） | `memory_map` | 全库词汇地图:项目 × 时间 × 高频实体 | ~1.5K |
| **L1 选线** | `memory_browse` | 某项目 / 某月的会话清单 | ~1K |
| **L2 上车** | `memory_search` | 用地图映射出的**原词**精确命中,直达消息坐标 | ~0.5K |
| **L3 到站速览** | `memory_digest` | 单场的任务 / 实体 / 结论 / 相邻会话 | ~1K |
| **L4 走到现场** | `memory_open` | 原文,按窗口翻页,永不整场注入 | 按需 |

**全程走完:~4K token。** 对比全文注入的几十万,是两个数量级。
而「库里到底有没有相关记忆」这个问题,在 L0 就用 1.5K token 得到答案——**没有,就此下车,1.5K 是全部代价。**

## 可达性定理:为什么敢说「全部上下文均可被查找」

检索会失手,结构不会。每一场对话都挂在三个确定的坐标上:**哪个工具 · 哪个项目 · 哪个月份**。

```
L0 地图 → 项目/月份 → L1 会话清单 → L3 速览确认 → L4 原文
```

这条结构路径不依赖任何关键词命中——**最多三次换乘,全库任何一场对话必然可达**。词法检索(L2)是它的快速通道:命中就抄近道,不中就回到结构路径。21.7% 是快速通道的单发命中率;**可达率是 100%,由结构保证,与检索运气无关。**

## 与向量 RAG 的分野

| | 向量 RAG | 记忆换乘 |
|---|---|---|
| 语义匹配由谁做 | 嵌入模型(需引入、需维护、需信任) | **对话另一头的 AI**(已在场,免费,更强) |
| 索引成本 | 全库向量化 + 常驻模型 | 零——地图是既有索引的一次聚合 |
| 可解释性 | 相似度分数,黑盒 | 每一跳可回查:哪个词、哪场对话、第几条消息 |
| 失败形态 | 相似但不对,难以察觉 | 落空明确报告,自动附赠下一站换乘建议 |
| 隐私 | 取决于嵌入跑在哪 | 全程本地,零网络 |

不是向量不好——是当对话另一头坐着一个大模型时,**再养一个小模型做语义匹配是重复建设**。把地图递给会读地图的人。

## 协议现状

- **L1–L4:已上线。** 五个 MCP 工具随 App 安装,只读,索引以 `SQLITE_OPEN_READONLY` 打开。
- **L2 四层增强:已上线。** BM25 双分词 · 个人词表(从你的语料学出的 3900+ 词)· RM3 查询扩展 · 项目情境加权,实测提升 4.2 倍。
- **落空附赠:已上线。** `memory_search` 空结果时自动附赠最近实体与可下钻分组,直接给出下一站。
- **L0 线路图 `memory_map`:规划中。** 尚未作为独立工具上线;目前不带参数调用 `memory_browse` 可拿到项目 / 月份 / 高频实体的库地图,先顶着 L0 的位置。
- **开场自动递图:规划中。** 会话开始自动注入 L0 地图(1.5K),AI 开口前就知道「有没有历史、在哪」。
